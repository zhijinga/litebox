# 声屿 · 本地媒体工具箱

## 图片批量压缩

在“图片压缩”标签中批量选择或拖入 JPG、PNG、WebP，可多次追加，每张最大 30 MB，最多 100 张。支持调整输出格式、JPG/WebP 质量和最长边尺寸；PNG 为无损编码，不使用质量滑块，体积可能增大。透明图片转 JPG 时填白，动态 WebP 仅输出静态画面。超过 4000 万像素的图片会跳过。

全部图片在浏览器内顺序处理，不上传本地服务或云端。可逐张下载，也可将成功结果打包成 ZIP；重名文件在压缩包中自动添加序号。单张失败不影响其他图片。切换工具保留图片结果，修改压缩设置需重新处理，刷新或关闭页面前请下载保存。原图片不会修改。

本地网页工具，支持拖放 MP4、128/192/320 kbps 音质、试听与下载。无需 Python 第三方库，不使用 CDN，文件不上传云端。每次处理一个文件，最大 2 GB。

## 视频画质增强

网页默认打开视频增强工具，也可切换回 MP4 转 MP3。

- 轻度增强：温和降噪和锐化，适合日常视频。
- 暗光降噪：较强降噪，适度提亮、调整对比度。
- 动画放大：轻度降噪和线条锐化。
- 支持保持原尺寸、1080p 和 4K 输出；保留横竖屏比例，不缩小更大的源视频。
- “预览前 5 秒”生成片段，与原视频对照后再处理完整视频。预览仍需在本机读取完整文件。

输出为 H.264/AAC MP4，原文件不变。视频没有音轨也可增强。此功能为 FFmpeg 滤镜增强，并非 AI 超分辨率，无法恢复已丢失的真实细节。放大可能增加文件体积和处理时间，每次处理最长一小时。结果需在刷新网页前下载保存。

## 换电脑后安装

先下载或克隆仓库，并解压到一个文件夹，不要在 ZIP 压缩包内直接运行。

### Windows（64 位 Intel / AMD）

1. 双击 `install.bat`，首次安装需要联网。
2. 脚本检测 Python 3.9+；缺少时尝试通过系统 winget 安装 Python 3.12，然后下载 FFmpeg。
3. 看到安装成功后，双击 `start.bat` 打开网页。
4. 关闭服务时，在启动窗口按 Ctrl+C。

如果系统没有 winget，请先从 https://www.python.org/downloads/windows/ 安装 Python 3，再重新运行 `install.bat`。Windows ARM 原生环境暂不自动下载 FFmpeg，需手动安装适配版本并加入 PATH。

### macOS（Apple 芯片 / Intel）

1. 双击 `安装.command`。
2. 脚本检测 Python；缺少时优先使用已有的 Homebrew 安装。没有 Homebrew 时打开 Python 官方下载页，需手动安装 Python 3 后重试。
3. 安装完成后双击 `启动.command`。

如果从 Git 获取的 `.command` 文件不能执行，可在项目目录运行 `chmod +x 安装.command 启动.command`。首次从网络下载的脚本可能需要按照系统提示确认来源。

### 安装机制与网络

安装脚本从 PyPI 的固定版本 `imageio-ffmpeg==0.6.0` 软件包获取对应平台的独立 FFmpeg，不需要通过 Homebrew 安装 FFmpeg，也不需要 pip 依赖。安装前核对 PyPI 提供的 SHA-256，安装后检查可执行程序和 MP3 / H.264 编码功能。软件包中的许可证一并保存在 `bin/`。

Python 的 HTTPS 证书不可用或下载失败时，会尝试使用系统 curl 重试，始终保留 HTTPS 证书校验。脚本不持久修改 PowerShell 执行策略；Windows 启动入口只对本次脚本进程指定执行策略。

已有可运行的项目内 FFmpeg 或 PATH 中的 FFmpeg 时直接复用，支持重复执行。FFmpeg 安装在 `bin/ffmpeg`（Windows 为 `bin/ffmpeg.exe`），该目录已加入 `.gitignore`，换电脑后重新运行安装脚本即可，不要把二进制文件提交到 Git。

命令行安装：`python setup.py`（macOS 使用 `python3`）。只检查环境：`python setup.py --check`。需要下载代理时：

```sh
python setup.py --proxy http://127.0.0.1:7890
```

端口请按实际代理配置填写。安装完成后可以离线使用，浏览器会打开 http://127.0.0.1:8765。也可直接在项目目录运行 `python server.py`。

转换会在系统临时目录写入视频和音频，请确保磁盘空间充足；请求结束后清理临时文件。网页下载链接在当前页面有效，刷新前请保存文件。音质设置决定输出码率，不能恢复原视频中已丢失的音频细节。服务仅监听本机 127.0.0.1，请勿用于公网部署。
